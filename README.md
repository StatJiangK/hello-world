# Hello World

这是一个用于练习 GitHub Flow 的示例仓库。  
它的目标是帮助新用户熟悉 GitHub 的基本协作流程，包括克隆、分支、提交、Pull Request 和合并。

## 项目简介

这个仓库可以作为一个最小示例项目，用于学习：

- GitHub 基础操作
- 分支管理
- 提交与版本控制
- Pull Request 流程
- 仓库维护和文档编写

## 快速开始

### 1. 克隆仓库

```bash
git clone https://github.com/StatJiangK/hello-world.git
cd hello-world
```

### 2. 创建分支

```bash
git checkout -b feature/my-change
```

### 3. 修改内容

在本地编辑文件后，完成你的更改。

### 4. 提交更改

```bash
git add .
git commit -m "Add new feature or update"
```

### 5. 推送到 GitHub

```bash
git push origin feature/my-change
```

### 6. 创建 Pull Request

在 GitHub 页面中创建 Pull Request，并请求代码审查与合并。
